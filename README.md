 # Assembly Language Programs

A collection of Assembly Language programs created while learning the fundamentals of Assembly programming. This repository includes basic programs, algorithm implementations, and practice exercises covering different Assembly concepts.

## Topics Covered

* Addition of two numbers
* Prime number program
* Factorial calculation
* Bubble Sort
* File handling
* Register flags
* Basic Assembly concepts and practice
